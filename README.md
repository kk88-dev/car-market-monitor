# Мониторинг рынка авто (AUTO.RIA)

Раз в несколько часов GitHub сам собирает объявления по вашему фильтру, следит
за ценами и фиксирует, когда машина продана или снята. Результат — дашборд по
постоянной ссылке.

## Как устроено

| Файл | Что делает |
|---|---|
| `config.json` | ссылка с фильтрами (`search_url`), название, лимиты API |
| `collector/collect.py` | сборщик: поиск → новые → пропавшие → обновление цен |
| `.github/workflows/collect.yml` | запуск каждые 3 часа на серверах GitHub |
| `docs/index.html` | дашборд (GitHub Pages) |
| `docs/data/*.json` | накопленные данные (их коммитит сам GitHub) |
| `collector/demo.py` | демо-данные, чтобы посмотреть дашборд без ключа |
| `tests/test_simulation.py` | проверка логики на поддельном рынке за 25 дней |

**Статусы объявлений**
- *продано* — продавец отметил «продано»;
- *снято* — объявление удалено или в архиве (часто это тоже продажа);
- *вышло из фильтра* — объявление живо, но больше не подходит под фильтр
  (например, продавец изменил цену или год); в статистику продаж не попадает;
- *перевыставлено* — продавец удалил и выложил машину заново; такие пары
  склеиваются по VIN или по совпадению характеристик, срок продажи считается
  от первого появления.

**Лимиты API.** Бесплатный ключ: 1000 запросов в месяц, 30 в час. Скрипт сам
делит месячный бюджет по дням. Поиск — 1 запрос на каждые 100 объявлений в день,
карточки — для новых и пропавших машин, остаток — на обновление цен (каждое
объявление примерно раз в `price_refresh_days` дней). При платном пакете
поменяйте `monthly_request_limit` и `hourly_request_limit` в `config.json`.

## Настройка (один раз)

1. **Ключ API.** developers.ria.com → личный кабинет → скопировать ключ.
2. **Секрет в GitHub.** Репозиторий → Settings → Secrets and variables →
   Actions → New repository secret. Имя: `RIA_API_KEY`, значение: ключ.
3. **Дашборд.** Settings → Pages → Source: *Deploy from a branch*,
   Branch: `main`, папка `/docs` → Save. Через минуту появится ссылка
   вида `https://<логин>.github.io/<репозиторий>/`.
4. **Первый запуск.** Actions → «Сбор объявлений» → Run workflow.
   Дальше всё запускается само.

## Локально

```bash
python3 collector/collect.py --show-params   # как ссылка переводится в фильтры API
python3 collector/demo.py                    # демо-данные для дашборда
python3 tests/test_simulation.py             # проверка логики
python3 -m http.server 8765 --directory docs # дашборд на http://localhost:8765
```
